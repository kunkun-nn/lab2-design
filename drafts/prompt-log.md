# AI 初稿提示词与输出摘要

- 时间：2026-10-30
- 工具/模型：DeepSeek 网页对话 / deepseek-chat

## AI-2.1 架构模块

提示词：根据实验一的需求，给出外卖点餐与配送系统的分层架构、模块划分和模块交互，说明为什么这样设计。

AI 输出摘要：三层架构；用户、店铺、订单、支付、配送五个模块；MySQL 存储；模块之间主要同步调用。

## AI-2.2 类图

提示词：用 PlantUML 画外卖系统的类图，包含用户、顾客、商家、店铺、菜品、订单和支付。

AI 输出摘要：User/Customer/Merchant/Shop/Dish/Order/Payment 七个类；merchant 与 shop 一对多；order 与 payment 一对一。

## AI-2.3 首页 UI

提示词：设计一个校园外卖顾客端首页，要好看，有店铺、菜品和购物车入口。

AI 输出摘要：顶部搜索、店铺列表、满减 banner、菜品卡片和底部购物车；使用了「满25减5」和「新用户立减10元」。

## 人工标注

- 架构初稿没有退款责任、审计日志、统计和通知，后续人工补充。
- 类图初稿缺少 Refund、DeliveryTask、DeliveryException、OperationLog，且没有订单状态和版本号字段。
- 首页初稿的优惠券/满减不在实验一范围内，最终稿删除。
